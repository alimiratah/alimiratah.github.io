# Mir Atah Ali IT Consulting LLC — Website

A lightweight static consulting website designed for GitHub Pages. No build tools or framework are required.

## Files
- `index.html` — site content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile menu, current year, and subtle reveal animation
- `.nojekyll` — tells GitHub Pages to serve the static files directly without Jekyll processing

## Preview locally
Open `index.html` in a browser. For the closest production-like preview, use VS Code's Live Server extension or run any simple local static server.

## Publish with GitHub Pages
1. Create a repository named `<your-github-username>.github.io`.
2. Add these files to the repository root.
3. Commit and push to the default branch.
4. In the repository's **Settings → Pages**, select deployment from the branch if Pages is not already enabled.
5. GitHub will publish the site at `https://<your-github-username>.github.io`.

## Custom domain later
In **Settings → Pages → Custom domain**, enter your domain. GitHub will provide/confirm the DNS configuration. Keep the repository name as `<username>.github.io`; you do not need to rename it for a custom domain.

## Before launch
- Confirm the email address and LinkedIn URL in `index.html`.
- Replace/add a custom domain when ready.
- Consider creating a dedicated business email on the custom domain later.
- If you have client-approved testimonials or anonymized case studies, add them after launch.
